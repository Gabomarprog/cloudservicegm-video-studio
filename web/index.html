Video Studio

Crea videos verticales de distintos temas con motion graphics HTML, CSS, SVG y GSAP. La IA escribe el guion y dirige las escenas; antes de renderizar puedes revisar y corregir la transcripción del audio.

1 Tema y dirección creativa

El director creativo usa Gemini 3.6 Flash. Tiene una cuota gratuita limitada; la clave solo se usa desde el servidor local y no se guarda en el repositorio.
Director creativo IA

Al generar una propuesta, la IA crea un guion original y elige escenas y objetos animados según el tema. No genera clips de video: dirige nuestra biblioteca de componentes HTML.

2 Fuente de narración

API key protegida: se utiliza para generar la voz y no se guarda en el repositorio.
Modelo eleven_multilingual_v2. Primero genera el guion con el director o escribe uno manualmente.
MP3, WAV, M4A, AAC, OGG, OPUS, FLAC o WEBM. Máximo 120 MB.
Sin API de voz: importa una narración generada en cualquier otra herramienta.

VISTA PREVIA Escucha la narración

El audio se envía a GitHub Actions para la transcripción. Todavía no se ensambla ningún video en esta fase.
