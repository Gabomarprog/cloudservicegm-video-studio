Video Studio

Elige cómo proporcionar la narración: generar con una API de voz o importar un audio creado en cualquier otra herramienta. Escúchalo antes de renderizar el video vertical en GitHub Actions.

1 Fuente de audio y datos del video

En modo importar no necesitas API key ni Voice ID.
API key protegida: se envía desde este panel local a ElevenLabs, no se guarda ni se manda a GitHub.
La conexión API integrada actualmente corresponde a ElevenLabs (modelo eleven_multilingual_v2). Otros proveedores requieren adaptadores de API específicos.
Admite MP3, WAV, M4A, AAC, OGG, OPUS, FLAC y WEBM. Tamaño máximo: 120 MB.
Sin API: puedes crear la narración con una web gratuita o con un programa de código abierto instalado en tu PC y subir aquí el archivo resultante.
En modo importar, los subtítulos se sincronizan a partir del audio real; el guion es opcional.
Listo. Elige una fuente de audio para comenzar.
